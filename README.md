# Electron Base Template

Template mínima para iniciar una aplicación de escritorio con Electron usando una configuración segura por defecto y una base preparada para tests y validación continua.

## Requisitos

- Node.js 24 LTS recomendado (mínimo 22.12.0)
- npm
- Git

## Tecnologías

- JavaScript
- HTML
- Electron
- Jest
- GitHub Actions

## Uso de la template

1. Usa **Use this template** en GitHub o clona el repositorio.
2. Instala las dependencias:

   ```bash
   npm install
   ```

3. Inicia la aplicación:

   ```bash
   npm start
   ```

Comandos disponibles:

```bash
npm test       # Ejecuta los tests con Jest
npm run check  # Comprueba la sintaxis JavaScript
npm run build  # Empaqueta la aplicación Electron
```
